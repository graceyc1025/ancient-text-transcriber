## 本次修正的运行故障

1. Tesseract.js 7 默认 SIMD 核心在浮点繁体模型上报 DotProductSSE 缺失函数，实际识别失败。当前固定使用实测成功的非 SIMD LSTM 核心。
2. WASM GetTSVText 不带命令行 TSV 表头。已接受真实无表头坐标格式，保留原本带表头支持及有效性检查。
3. Worker 加载失败有时以 undefined 拒绝；原错误显示代码会再次报错导致界面卡住。已规范错误显示，故障时保留人工底稿并恢复操作。
4. 子路径测试服务器先前因目录尾斜线检查误报 404，已修正；这不是生产 OCR 后端。

部分旧模型参数会产生控制台未识别参数提示。本次非 SIMD 核心实际完成了 OCR；参数兼容提示和功能成功均不能代替精度评测。

## 实际浏览器识别质量

以下数据来自 npm run test:ocr-samples，通过真实网页操作记录，不使用 Python OCR 或模型模拟。默认阈值 65。

| 样例 | 输出字符数（不计列换行） | □ 数量 | 约耗时 | 字符错误率 CER |
| --- | ---: | ---: | ---: | --- |
| 合成竖排图 | 30 | 6 | 0.88 秒 | 23.3%，7/30（含□） |
| 合成横排图 | 19 | 3 | 1.03 秒 | 15.8%，3/19（含□） |
| 毛詩排印内容页 | 385 | 99 | 5.64 秒 | 没有逐字真值，不计算 |
| 书写/印章扫描页 | 82 | 70 | 5.26 秒 | 没有逐字真值，不计算 |

首次竖排模型载入加识别约 1.45 秒；以上只是本环境本次运行时间，使用者网速和硬件不同会改变耗时。模型缓存、引擎初始化等条件影响计时，不能承诺所有电脑的速度。

CER 为去掉版面换行后的编辑距离除以参考字数，□计作未正确转录。输出字数并非原图应有字数，□比例也不是错误率。阈值 0 时同一合成竖排图 CER 为 20%（6/30），没有□；阈值提高只是标疑，并不会自动提升模型识别能力。

默认阈值 65 的竖排输出原样如下，未润色或补字：

```text
學而時習之不□□□
有朋自遠方來不□樂□
人不知而不惱不□君子乎
```

参考文字只用于质量计算，不作为模型输入或校正模板：

```text
學而時習之不亦說乎
有朋自遠方來不亦樂乎
人不知而不慍不亦君子乎
```

例如“慍”仍被高置信度误识为“惱”，没有全部被标□。书写扫描页有大量□和明显漏检/错误列，这是当前通用模型无法可靠处理复杂古籍的直接证据。

- 没有自动古籍版面分类、可靠异体字专用模型、缺字位置推断、完整脱网重开网页、会话恢复或校勘版本历史。
- 框外内容不补入，模型漏检不自动补□；研究引用必须逐字对照原图。
- 改造前 Python 版的测试结果不用于证明本浏览器版的性能，本报告已替换旧版测试结论。

## 重现

```bash
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:ocr-samples
# 有权使用并保存扫描样例后，可追加：
npm run test:ocr-samples -- /path/to/maoshi.png /path/to/page_2.png
```

本机存在 /usr/bin/chromium 时测试自动使用它，也可设置 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH。普通用户无需执行这些维护命令。截图、下载检查文件、trace 和真实测量 JSON 写入被忽略的 test-results/playwright-report，不包含在网站产物中。
