# 对照测试工具验收记录

2026-10-15，实验分支 `experiment/paddleocr-v5-browser`。本轮仅完善实验入口、评分和记录工具；未修改正式入口、根依赖或 Pages 工作流，未合并或发布。

**仓库缺少真实清代书页和可靠人工标准的配对样本，清代准确率未测试。** 下表使用现代合成 `example.png`（740×900、30 个标准码位）验证真实 OCR 流程，不证明刻本、石印本、版心、异体字或行草的适应性。该图与人工核对的标准稿来自既有演示测试；不能当作清代样本。

环境：Linux x64，Chromium 154.0.8037.57，每种方法独立新建浏览器，1440×1100 桌面视口；共同原尺寸、3 栏，去半角布局空白，其余 Unicode 码位严格比较。Tesseract 使用 chi_tra_vert、PSM 5；Paddle 使用固定社区导出的 PP-OCRv5 mobile 权重及官方固定字典。Paddle 识别分数阈值 0，检测阈值 0.3/0.6、扩框比 2。完整来源、哈希、参数、原始文本、逐字对齐和采样结果见[实际验收数据 JSON](清代对照工具验收数据.json)。

这里只是一次流程验收，不是重复测量统计或资源上限。PSS 包含浏览器本身，约 100ms 采样可能漏过瞬时峰值；初始化受文件/操作系统缓存影响。不要和网页上的主页面 JS 堆值混用，也不要把本表与旧报告不同参数的结果解释成清代精度变化。

标准稿：

```text
學而時習之不亦說乎
有朋自遠方來不亦樂乎
人不知而不慍不亦君子乎
```

两个 Tesseract 方法的几何序候选均为：

```text
學而時習之不亦說乎
有朋自遠方來不亦樂乎
人不知而不骨不亦君子乎
```

两个 Paddle 方法的几何序候选均为：

```text
學而時習之不亦說乎
有朋自方來不亦樂乎
人不知而不慍不亦君子乎
```

Tesseract 将「慍」错成「骨」，Paddle 漏「遠」。Paddle 整页的原生 SDK 输出从左栏起，几何排序前的原文为：

```text
人不知而不慍不亦君子乎
有朋自方來不亦樂乎
學而時習之不亦說乎
```

因此记录同时包含原生顺序和几何顺序评分，不能用排序后结果冒充引擎原生阅读顺序。各栏完整原始 TSV / SDK items 均保存在 JSON。

已通过的检查：

- 实验单元测试 8 项：精确异体/IVS/标点比较、存疑标准不计分、共享裁栏、负数/缺失置信度候选不隐藏、CSV 不以 0 冒充缺失测量、模型来源固定等。
- `npm run test:case`：实际上传图片和标准 TXT、四次真实识别、共同裁栏/尺寸、原始输出、标准修改不影响旧记录、输入/记录 JSON 和 CSV 导出、输入哈希验证、四个独立浏览器进程树内存采样。
- 故障验收仅注入模型 HTTP 404，不模拟 OCR 输出；Tesseract 两项完成，Paddle 两项明确失败、CER 为 null，既有候选保留。
- 实验构建通过；同源请求仅 GET/HEAD，无图片上传或第三方识别请求；在 GitHub Pages 项目子路径形式下运行，无 COOP/COEP 要求。
- 桌面、触屏手机模拟、缺模型故障的原有三项实验检查通过。手机只是 Chromium 模拟，没有 Android/iPhone 真机验证。
- 原项目构建、18 项单元测试、7 项浏览器测试通过，覆盖批量 JPG/PNG、框选、实际 OCR、校对、复制、TXT/DOCX 导出和失败恢复。
