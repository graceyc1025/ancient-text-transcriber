# 第三方引擎、模型与许可

- Tesseract.js 7.0.0：<https://github.com/naptha/tesseract.js>，Apache-2.0，原许可见 tesseract-js-LICENSE.txt；构建还将原许可随 Worker 静态发布。
- tesseract.js-core 7.0.0：<https://github.com/naptha/tesseract.js-core>，Apache-2.0，见 tesseract-core-LICENSE.txt。实际锁定版本以 package-lock.json 为准。
- docx 9.10.0：<https://github.com/dolanmiu/docx>，MIT，见 docx-LICENSE.txt。
- tessdata_best 模型：<https://github.com/tesseract-ocr/tessdata_best>，Apache-2.0，见 tessdata-LICENSE.txt。固定上游提交 e12c65a915945e4c28e237a9b52bc4a8f39a0cec，模型内容未修改，仅采用确定性 gzip 压缩并发布在 public/ocr/tessdata。构建验证解压后的 SHA-256。

其他软件包和构建/测试依赖的版本、完整性记录见 package-lock.json；各包随附其许可证。

实验分支的 Paddle 试用另包含：官方 `@paddleocr/paddleocr-js` 0.4.2（Apache-2.0）、其分发的 OpenCV Worker 及相关 Clipper/JSBN/js-yaml 组件、ONNX Runtime Web 1.24.3（MIT）和社区导出的 PP-OCRv5 mobile 模型包 `pdfmarkdown-ppocrv5-models@1.0.0`（Apache-2.0）。权重来自固定上游提交 `384182c7187c12d4ea181ae3b97c8b7e12089d9d`，使用固定官方字典，未改权重；不是与未取得的官方原始模型tar逐字节相同的声明。模型格式、字典及权重/tar哈希见 `experiments/paddle/models.json`。构建复制许可到 `paddle/licenses/` 并随静态测试包分发；SDK Worker中仍保留其版权/许可注释。本轮只集成试用，不宣称模型专门面向清代异体字或行书训练。

演示图片为本项目现代生成的竖排/横排繁体排版，用 Noto Serif CJK 字体渲染，不分发字体文件，不声称它们是古籍原页。真实外部书页样例仅暂存用于测试；上游未明确授予样例再分发许可时不发布在网站或提交到仓库。样例来源和测量见测试报告。
